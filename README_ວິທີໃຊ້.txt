Bai Boua Shop - Project Package
================================

ໄຟລ໌ນີ້ເປັນ ZIP ລວມໂປຣເຈັກເວັບ Bai Boua Shop.

ໄຟລ໌ຫຼັກທີ່ໃຊ້ງານ:
- latest/BaiBoua_shop_supabase_v8.html

ໄຟລ໌ຖານຂໍ້ມູນ Supabase:
- database/BaiBoua_supabase_setup.sql

ວິທີເຊື່ອມ Supabase:
1. ເຂົ້າ Supabase Project ຂອງເຈົ້າ
2. ໄປທີ່ SQL Editor
3. Copy ໂຄ້ດຈາກ database/BaiBoua_supabase_setup.sql
4. ກົດ Run
5. ເປີດ latest/BaiBoua_shop_supabase_v8.html ໃນ Browser

ໂຟນເດີທີ່ມີໃນ ZIP:
- latest/ = ໄຟລ໌ເວັບລ່າສຸດທີ່ເຊື່ອມ Supabase
- database/ = SQL ສຳລັບສ້າງ table ໃນ Supabase
- old_versions/ = ໄຟລ໌ backup ເວີຊັນກ່ອນໜ້າ
- assets_qr_and_images/ = ຮູບ QR / ຮູບອ້າງອີງ
- project_spec/ = ສະເປັກລະບົບທີ່ໃຫ້ມາ

ໝາຍເຫດ:
ໄຟລ໌ HTML ນີ້ຍັງເປັນຕົວແບບແບບ frontend-first. ຖ້າຈະນຳໄປໃຊ້ຂາຍຈິງແນະນຳໃຫ້ເຮັດ backend/auth/RLS security ໃຫ້ຄົບກ່ອນ.
